# Kloyce Context

## Language

**Retained Recording**:
Audio kept for the retention window to allow reprocessing.

**Retention Window**:
24 hours.

**Failed Transcription**:
A persisted record of a hotkey transcription that errored, reprocessable while audio remains.

**Voice Tag**:
The clarification note prefixed to delivered transcripts.

**Cleanup Engine**:
An optional transcript post-processor; deterministic filler removal is the default posture.
